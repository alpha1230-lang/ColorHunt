# COLOR HUNT PWA v4
- ハイスコア保存
- ランダムな色パレット
- ピンチズーム・ドラッグ移動
- 色差を0.1%まで手動調整（明度差のみで比較）
- レベル上昇に応じて色差が縮小
- ゲーム内ランク、正答率、最小クリア色差を表示
- お助けモード

## GitHub更新
